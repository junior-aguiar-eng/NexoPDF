NexoPDF portable mode

While this file sits next to nexopdf.exe, NexoPDF keeps its settings, log files, crash-recovery
autosaves and new digital IDs in the NexoPDFData folder beside it, and writes nothing to
%APPDATA% or %LOCALAPPDATA%. Copy the whole folder to move NexoPDF with its settings.

Delete this file to use the normal per-user folders (%APPDATA%\NexoPDF and
%LOCALAPPDATA%\NexoPDF) instead. If NexoPDFData can't be written (for example on a read-only
drive), NexoPDF says so and uses the per-user folders instead.
